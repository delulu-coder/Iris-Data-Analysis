# 🌸 Iris Dataset Analysis

## 📌 Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Iris dataset using Python. The goal is to understand data patterns, relationships, and distributions through visualization.


## 🎯 Objective
- Explore dataset structure  
- Analyze feature relationships  
- Visualize distributions  
- Identify patterns and insights  


## 🛠️ Tools Used
- Python  
- pandas  
- seaborn  
- matplotlib  


## 📊 Dataset
The Iris dataset contains 150 samples of iris flowers with the following features:
- Sepal Length  
- Sepal Width  
- Petal Length  
- Petal Width  
- Species  



## 🔍 Analysis Performed
- Data inspection using `.info()` and `.describe()`  
- Scatter plots for feature relationships  
- Pairplots for multi-feature comparison  
- Histograms for distribution analysis  
- Boxplots for outlier detection  
- Correlation heatmap  

---

## 🧠 Key Insights
- Dataset has no missing values  
- Petal length and width are highly correlated  
- Clear separation between species  
- Petal features are more useful for classification  


## ✅ Conclusion
This project highlights the importance of understanding data through visualization before applying machine learning models.
